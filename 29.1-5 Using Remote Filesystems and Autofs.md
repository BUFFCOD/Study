## 29.2 Mounting NFS Shares

Make sure that nfs-utils is installed.

Use showmount -e nfsserver  to show exports

use mount nfsserver:/nfsdata /mnt to mount the share

## Configuring AutoMount (autofs) for NFS Shares

While setting up autofs for a directory, pre-autofs contenet is  no longer accessible.


In /etc/auto.master you'll identify the directory that autofs should manage, and the file that is used for additonal mount information.
   - /data /etc/auto.nfsdata

In /etc/auto.nfsdata you'll specify the mount point and the NFS server and share.
    - nfsdata -rw nfsserver:/nfsdata

  Ensure autofs is started and enabled.
   - systemctl enable --now autofs

  
  Tip check /etc/auto.misc for syntax examples.


  ## 29.4  Setting up a Autofs for Home Directories

  Autofs is common for homedirectory access.

  In theis scenari, an NFS server is providing access to home directories, and the home directories is automatically mounted when a user logs in.

  To support differnet directories names in one line, wildcards are used

    * -rw nfsserver:/home/ldap/ldapuser&


## 29.5  Using Remote Filesystems and Autofs

Systemd automount units can be used with mount units to mount a filesystem only when the mount directory is accessed.

Systemd automount does not offer wildcard mounts.

To configure a systemd automount, create mydir.automount for the matching mydir.mount unit.

While using automount you should enable the auto mount not the mount unit

see nfsdata.mount and nfsdata.automount  in the course Git repository at https://github.com/sandervanvugt/rhcsa10 for an example.
